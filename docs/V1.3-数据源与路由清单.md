# 🗺️ 路由与页面清单（页面名称 \+ 功能说明 \+ UI 参考开源仓库，v1\.3 新增，交给 Agent 开发页面参考）

## 🏠 Tabbar 底部主页面

1. **首页 / 推荐页**

- 功能：精选文言文推荐、朝代分类、今日一篇、热门篇目、学习进度卡片

- UI 参考：诗词 App 首页卡片布局

- 参考仓库：hzpt\-inet\-club/uni\-app\-poetry [https://github\.com/hzpt\-inet\-club/uni\-app\-poetry](https://github.com/hzpt-inet-club/uni-app-poetry)

2. **篇目库**

- 功能：全部文言文库，按学段 / 朝代 / 体裁筛选，搜索文言文篇目，收藏篇目

- UI 参考：书籍列表，分页加载，水墨缩略封面

- 参考仓库：TruthHun/BookChatApp [https://github\.com/TruthHun/BookChatApp](https://github.com/TruthHun/BookChatApp)

3. **背诵广场**

- 功能：实词、虚词、通假字卡片记忆，艾宾浩斯 SRS 复习，背诵打卡

- UI 参考：知识点记忆卡片，翻卡交互

- 参考仓库：yangyijie912/kc\-uniapp\-project [https://github\.com/yangyijie912/kc\-uniapp\-project](https://github.com/yangyijie912/kc-uniapp-project)

4. **我的**

- 功能：个人学习数据、已收藏、已读完、错题本、设置（字体、阅读背景、主题）

## 📄 二级跳转页面（非 Tab 页面）

1. **文言文阅读页【核心页面】**

- 功能：正文展示、逐句注释弹窗、译文切换、赏析、字体大小调节、背景切换（宣纸 / 护眼）、书签、划线笔记，预留竖排古文备选模式

- UI 参考：阅读器长文本排版

- 参考仓库：TruthHun/BookChatApp [https://github\.com/TruthHun/BookChatApp](https://github.com/TruthHun/BookChatApp)

2. **篇目详情页**

- 功能：作者介绍、朝代、原文、翻译、重点字词预览，进入阅读按钮

- UI 参考：诗词详情页布局

- 参考仓库：weypro/poetry [https://github\.com/weypro/poetry](https://github.com/weypro/poetry)

3. **默写刷题页**

- 功能：挖空默写、句子填空、实词选择题、提交批改、解析展示

- UI 参考：卡片答题

- 参考仓库：yangyijie912/kc\-uniapp\-project [https://github\.com/yangyijie912/kc\-uniapp\-project](https://github.com/yangyijie912/kc-uniapp-project)

4. **错题本页面**

- 功能：错题汇总，按篇目 / 知识点筛选，重新练习，清除错题

- UI 参考：错题列表 \+ 再次答题卡片

- 参考仓库：yangyijie912/kc\-uniapp\-project [https://github\.com/yangyijie912/kc\-uniapp\-project](https://github.com/yangyijie912/kc-uniapp-project)

5. **搜索结果页**

- 功能：全文检索文言文、字词检索，搜索历史

- UI 参考：诗词搜索页

- 参考仓库：hzpt\-inet\-club/uni\-app\-poetry [https://github\.com/hzpt\-inet\-club/uni\-app\-poetry](https://github.com/hzpt-inet-club/uni-app-poetry)

6. **学习设置页**

- 功能：阅读字体切换（霞鹭文楷、马叙伦楷、系统字体），宣纸背景 / 夜间模式，字号，行间距，背诵打卡提醒时间设置
