## 1 产品需求与权限规则

### 1\.1 用户登录 \& 首次初始化完整新手流程

1. 登录页：微信、QQ OAuth 登录，无手机号登录入口

2. 登录成功，读取用户标记 `is_first_init`

- ✅ `is_first_init = 1`（新用户）

- 步骤1：年级选择页面，可选学段：初中 / 高中；选中存入用户配置，后续个人设置页支持修改

- 步骤2：新手蒙层引导，依次介绍核心功能：卡片学习、默写刷题、题库练习、错题本、组卷打印，用户点击完成引导

- 步骤3：跳转首页；后端更新 `is_first_init = 0`

- ✅ `is_first_init = 0`（老用户）直接进入首页，跳过新手全部流程

### 1\.2 打卡定时邀约提醒

- 触发条件：用户提交任意第一次作答（默写提交 / 真题刷题提交）之后触发弹窗，仅自动弹出一次

- 弹窗文案：我们要不要约定一个时间，定时打卡训练文言文啦？

- 组件：时间选择器 HH:mm

- 按钮：【确定开启提醒】｜【暂时跳过】

- 确定开启：保存用户选定时刻，开启打卡提醒开关

- 暂时跳过：不开启提醒，后续不再自动弹出邀约弹窗，仅可手动在设置页开启/修改

- 通知内容：`@{用户昵称}，该来打卡训练文言文啦！`，推送携带昵称

- 双推送通路：APP本地通知 \+ 微信小程序服务通知；同一天同一用户仅推送一次，防骚扰

- 入口：个人设置页随时关闭提醒、修改打卡提醒时间

- 可视化打卡日历：「我的」页面嵌入打卡日历组件，高亮标记当日以及历史打卡完成日期，直观展示连续打卡天数、学习记录

### 1\.3 永久免费功能清单

1. 微信 / QQ OAuth登录、SRS卡片复习

2. 双体系错题本全部免费；错题组卷、自定义题库组卷、HTML浏览器打印免费

3. 小学初中高中课文库原文、翻译、赏析免费阅读

4. 打卡日历、定时打卡提醒免费

5. 斩词免费额度：初始150个，仅斩词消耗额度；复习、默写、刷题不消耗额度

6. 中考、高考基础题库免费刷题，含高考理解性默写题型

### 1\.4 付费商业化规则

1. 免费额度耗尽：购买额度包（最低购买300额度，无上限，支持自定义输入购买数量）或者开通会员

2. 会员权益：斩词无上限、默写不限次数、高考高阶真题套卷解锁、PDF试卷导出、AI自定义词包、导出学习报告

3. 双重校验：PDF导出、学习报告导出，同时校验「会员有效状态 \+ 用户手机号绑定」

### 1\.5 默写模块

1. `write_exercise` 配套默写练习，支持打字输入 \+ 讯飞ASR语音转写

2. ASR识别结果强制允许用户手动编辑之后提交判分，不能直接拿语音结果批改

3. 默写草稿保存在设备本地；提交作答后，作答记录存入MySQL，答错自动归入字词错题库

### 1\.6 中考 \& 高考题库

题型枚举：`SINGLE`单选、`MULTI`多选、`TRUE_FALSE`判断、`UNDERSTAND_DICTATE`理解性默写、`DIRECT_DICTATE`直接默写、`SENTENCE_BREAK`断句、`WORD_EXPLAIN`实词解释、`TRANSLATE`翻译、`CONTENT_QUESTION`简答

- `exam_level`：2=中考，3=高考；基础题库全部免费；高阶真题套卷会员专属

- 用户做题记录存入独立表 `user_exam_record`，独立真题错题集合，和字词错题分开

### 1\.7 组卷打印功能

1. 两个组卷入口：①错题本勾选错题组卷；②真题题库手动选题自定义组卷

2. 试卷数据存储后端；支持预览、重命名、增删题目、删除试卷

3. HTML浏览器打印全部用户免费；PDF试卷导出会员专属

4. 组卷数据源限制：仅使用 `exam_question` 真题题目，`write_exercise` 默写练习题不能参与组卷

5. 字词SRS错题关联真题题目，如果找不到对应真题，过滤并且弹窗提示用户

### 1\.8 打卡定时通知规则

1. Spring定时任务，按用户设置的提醒时刻推送通知，消息携带用户昵称

2. 用户随时在个人设置关闭提醒、修改打卡提醒时间

3. 跳过首次邀约弹窗≠永久关闭，设置页可以手动开启

## 2 整体技术架构

### 后端

- JDK17 \+ SpringBoot3 \+ Maven多模块 \+ MySQL8\.0 \+ Redis

- 框架组件：MyBatis‑Plus、Lombok、Hutool、Validation；统一Result返回、全局异常处理器、token拦截鉴权

- 新增组件：Spring Scheduled定时任务、小程序服务通知接口、APP推送对接

- 第三方对接：微信/QQ OAuth、讯飞ASR、微信支付回调

### 前端 Uni‑App【新版技术基线】

技术基线：UniApp Vue3 \+ TS \+ Vite \+ UnoCSS，文艺国风（宣纸米白、墨黑、赭石配色，支持霞鹭文楷 / 马叙伦楷字体）
用途：文言文学习、篇目阅读、注释查阅、实词虚词背诵、默写刷题、错题复习

- Vue3 \+ TS \+ Vite \+ Pinia \+ UnoCSS（优先脚手架 unibest），备选轻量脚手架 uniapp\-vue3\-template

- 跨端目标：H5、微信小程序、APP

- 字体支持：霞鹭文楷、马叙伦楷、系统默认字体，阅读页可切换

- 配色体系：宣纸米白国风主题（UnoCSS自定义变量），同时保留夜间模式

- 存储规范：Pinia维护token、用户状态；`uni.setStorageSync` 只保存未提交默写草稿、UI偏好；所有业务数据请求后端接口，前端不持久化业务数据

## 3 Maven 多模块工程结构

父工程名称：`wenyan‑zhan`

```Plaintext
wenyan‑zhan (父pom，dependencyManagement统一版本管理)
├── wenyan‑common        # 公共工具、常量、自定义异常、Result返回体、通用工具类
├── wenyan‑entity        # POJO实体、DTO、VO
├── wenyan‑mapper        # Mapper接口
├── wenyan‑service       # Service业务层
└── wenyan‑api           # SpringBoot启动模块、Controller、yml配置、拦截器、定时任务
```

依赖顺序：`common → entity → mapper → service → api`

1. `sys_user` 新建记录：`is_first_init = 1`

2. 同步插入 `user_setting` 空记录，默认字体、宣纸背景

3. `user_word_quota` 初始化：`free_quota=150`，`buy_quota=0`，`used_quota=0`

## 6 核心业务逻辑详细说明

### 6\.1 新用户首次初始化流程

1. OAuth登录成功读取 `sys_user.is_first_init`

2. `is_first_init=1`：前端年级选择页 → 提交保存 `study_grade` → 新手蒙层引导完成 → 后端更新 `is_first_init=0` → 跳转首页

3. `is_first_init=0`，直接进入首页

### 6\.2 首次做题打卡邀约弹窗逻辑

1. 用户提交第一次作答（默写提交 / 真题做题提交）后端校验该用户是否触发过打卡邀约

2. 未触发：接口返回标记 `showRemindPopup: true`，前端弹出打卡邀约弹窗；标记用户已经触发邀约，不再重复弹出

3. 用户点击开启：保存 `remind_switch=1 + remind_time`

4. 用户跳过：不修改设置，不再自动弹窗，仅设置页手动开启

接口约定：`/api/write/submit`、`/api/exam/question/submit` 返回字段 `showRemindPopup: boolean`

### 6\.3 定时打卡通知（后端定时任务）

1. Spring Scheduled 每分钟执行扫描任务

2. 筛选条件：`remind_switch=1`，`remind_time`等于当前时分，并且 `user_push_record`不存在今日该用户推送记录

3. 组装推送文案，携带用户昵称，分发APP推送、小程序服务通知，写入 `user_push_record` 记录本次推送

4. 保证同一天同一个用户最多推送一次

### 6\.4 打卡日历统计逻辑

1. 前端请求后端打卡统计接口，传入年月

2. 后端查询 `user_word_record / user_exam_record` 的 `submit_time`，去重日期得到当月打卡日期集合，同时返回连续打卡天数、当月打卡总天数

3. 返回打卡日期数组，前端日历组件渲染高亮打卡日期

### 6\.5 SRS 记忆逻辑

- `memory_level = 0`：完全不认识

- 标记模糊：`memory_level` 不变，复习间隔1天

- 标记认识：`memory_level+1`，复习间隔 = $2^{level}$ 天

- `memory_level = 99`：斩词完成，不再安排复习

- Redis缓存用户今日待复习的字词ID集合，加速首页任务加载

### 6\.6 斩词额度校验

- 会员状态有效：斩词不消耗额度

- 非会员：校验剩余额度，斩词动作扣减 `used_quota`；额度不足返回提示

- 额度购买校验：购买数量最小300，小于300直接拒绝

### 6\.7 默写业务

ASR语音识别文本支持用户手动编辑，提交后端统一判分；答错自动加入字词错题，存入 `user_word_record`；草稿本地保存，提交后写入MySQL

### 6\.8 组卷业务

1. 错题本组卷：真题错题直接取 `questionId`；字词SRS错题，根据 `word_id` 匹配关联 `exam_question`，匹配不到过滤并且提示用户

2. 自定义题库组卷：手动勾选题目，支持试卷重命名、增删题目、删除试卷

3. HTML打印全部开放；PDF导出双重校验：会员有效 \+ 手机号绑定

### 6\.9 双错题体系

- 字词背记错题来源：`user_word_record`

- 真题刷题错题来源：`user_exam_record`
两套错题互相独立，都支持专项复习、一键清空错题
